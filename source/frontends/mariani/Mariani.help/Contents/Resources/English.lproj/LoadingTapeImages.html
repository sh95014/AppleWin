Loading Cassette Tapes

You can load software stored on cassette tape image files into Mariani.

To load a cassette tape image

  1. Boot into a BASIC prompt.
  2. Select "Load Tape..." from the File menu.
  3. Navigate to the tape image you want to load, and click "Open". You should see a tape icon appear in the status bar.
  4. Type LOAD in the BASIC prompt and press the Return key.
  5. The tape icon should start blinking until the program is loaded.

Note that loading from tape will force the CPU back to authentic speed.
