Loading and Saving State

Most of the emulated Apple II's state can be saved to a file and restored at a later time. This can be useful for continuity across Mariani sessions or to help with games that don't have a save option.

To save the emulator's state

  1. Select "Save State" or "Save State As..." from the File menu, depending on whether you would like to specify a different file name. Pressing the F11 key is equivalent to the former.

The location of the state file will be displayed in the status bar when complete.

To restore the emulator's state

  1. Select "Load State..." from the File menu or press the F12 key.
  2. Locate the state file and click "Open".

The following are persisted to the file:

  • Apple model: II, II Plus, //e (original), //e (enhanced) or clone (eg. Pravets)
  • Apple II's slot-0 language card: 16K Language Card, Saturn 64K or Saturn 128K
  • Apple //e's auxiliary card: 80 Column, Extended 80 Column or RamWorks III
  • Any Apple II: Saturn 128K cards in slots other than slot 0
  • Disk II (even during r/w operation)
  • Hard disk (even during r/w operation)
  • Mockingboard & Phasor cards
  • SAM card
  • Mouse card
  • CP/M SoftCard
  • Parallel Printer card
  • Super Serial card
  • No-Slot clock
  • Uthernet & Uthernet II cards
  • 4Play & SNES MAX joystick cards
  • VidHD card
  • Game I/O Connector copy protection dongle

The following are not yet persisted to the file:

  • Using The Freeze's F8 ROM
  • Alternate F8 ROM
  • Alternate ROM
  • Alternate video ROM
