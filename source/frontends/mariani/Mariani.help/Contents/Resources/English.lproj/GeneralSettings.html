General Settings

Screenshots
Selects the directory in which to store screenshots.
Recordings
Selects the directory in which to store screen recordings.
Recording Quality
Selects the encoding quality of the screen recordings. Higher quality recordings will consume more space and may affect the fidelity of the emulation.
Map Delete key to Left Arrow
The Apple II's Delete key doesn't typically work like the "backspace" that Mac users may be accustomed to. Selecting this option will map the Mac's Delete key to the Apple II's ← key instead.
Take screenshots based on window size
Screenshots are normally taken at the Apple II's native size of 560×384 pixels. Select this option to take screenshots at the size of the emulator's window instead.
Automatically check for updates
Mariani will sporadically check GitHub on launch to see if a new version is available. No personally-identifiable information is sent to me or GitHub but some metadata like origin IP address might be logged by GitHub.
